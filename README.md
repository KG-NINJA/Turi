# シビア釣りタイミングゲーム

タイミングよくボタン（または Space / Enter）を押して魚を釣る、シンプルなブラウザゲームです。
水面には魚が泳ぐアニメーションとヒット時の水しぶき演出があり、釣りの雰囲気を楽しめます。

## 遊び方

1. `index.html` をブラウザで開く。
2. 白いカーソルが赤い `HIT` ゾーンに重なった瞬間にタップして「合わせる」。
3. ヒットしたら長押しで巻き取り、テンションを適正ゾーンに維持する。
4. 一定時間、糸が緩すぎる/張りすぎる状態が続くと失敗。
5. 駆け引き時間を耐えきれば釣り上げ成功。

## ローカル起動例

```bash
python -m http.server 4173
```

その後 `http://localhost:4173` を開いてプレイしてください。
